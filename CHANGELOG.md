# Changelog

## 0.1.0-alpha.1 — 2026-09-10

Initial packaged research snapshot of the supplied Phase 8 source.

- Preserve all 57 library modules, nine top-level Lean entry points, dependency
  pins, verification scripts, and the working manuscript.
- Add a project overview, citation metadata, GitHub Actions verification,
  release notes, source provenance, and publishing instructions.
- Document the observed-process and Fréchet–Hilbert correspondence work and
  the planned manuscript corrections.
- Preserve the original development notes and supplied verification record.

This is a packaging release. It makes no changes to Lean definitions, theorem
statements, proofs, or manuscript mathematics. Historical phase notes describe
earlier milestones; current limitations are in [docs/STATUS.md](docs/STATUS.md).
